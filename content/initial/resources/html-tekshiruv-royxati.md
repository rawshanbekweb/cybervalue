# HTML Page Review Checklist

Version: 1.0. Language: English.

Use this checklist for independent practice. It does not replace the assessment rubric.

## Document

- [ ] A DOCTYPE is present.
- [ ] The document's lang value matches the language of its content.
- [ ] UTF-8 character encoding is declared.
- [ ] The page title describes its content.

## Content

- [ ] The main heading and sections follow a logical order.
- [ ] Each paragraph develops a separate idea.
- [ ] Lists use appropriate list elements.
- [ ] Link text explains the purpose of its destination.
- [ ] Image descriptions match each image's purpose on the page.

## Self-review

- [ ] I compared the source code with the preview.
- [ ] I found at least one mistake and explained its cause.
- [ ] I can explain why I chose each HTML element.
