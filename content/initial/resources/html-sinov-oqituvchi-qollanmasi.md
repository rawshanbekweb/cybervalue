# HTML Assessment: A Quick Guide for Teachers

Version: 1.0. For the CyberValue assessment module.

## Before the assessment

1. Create an assessment at /admin/assessments.
2. Set a time limit between 15 and 120 minutes.
3. Enter students in the format ID | Full Name.
4. Download the TXT file immediately after generating codes. Plaintext codes cannot be viewed again later.
5. Give each code only to the student it belongs to.

## Student workflow

- Open /playground/html-basics/assessment.
- Checking a code does not start the timer.
- Starting the attempt sets a server-side deadline.
- Refreshing the same browser resumes the saved attempt.
- An attempt cannot be recovered after deleting its cookie or switching browsers.

## Scoring

- 6 questions: 30 points total.
- 12 practical criteria: 60 points total.
- Two explanations: 10 points total, reviewed by the teacher.
- Preliminary automated result: /90; final result: /100.

Review the code and explanations, then enter 0–10 points in the manual review field. For each explanation, award 0–2 for accuracy, 0–2 for reasoning, and 0–1 for an example from the student's code.

## Supervision and results

Tab switches and other browser signals do not automatically reduce scores. They cannot reliably detect outside assistance. Teacher supervision is still necessary. Results can be downloaded as CSV from the admin page.

Do not distribute access codes or individual results to a shared group.
